# Intake

## Collect

From the user, now:

1. **Ability** — one named how-to (the SomeSkill).
2. **Entry** — create (new) or evolve (existing).
3. **Pointers** — each history they want distilled, and for each: the bundled extractor they name, or **Read**.
4. **Path** — where SomeSkill lives or will live.

If a packager skill is attached (create-skill or similar), use it for layout only. DistillingAnyone owns the body.

## Stop

Path missing → stop. Ask for the path. Invent nothing.

A pointer with no extractor and no **Read** → stop. Ask which.

Ability unnamed or broader than one how-to → stop. Ask them to name one ability.

## Done

A card exists with ability, entry, every pointer paired to an extractor or **Read**, and an existing or intended SomeSkill path. Scratch id is chosen (`/tmp/distill-<run-id>/`).
