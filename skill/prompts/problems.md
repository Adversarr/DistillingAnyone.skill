# Problems

## Slice

From `coverage.md` and the human corpus, list every **checkable** problem: a distinct outcome a later agent can be scored on (a number, a decision, a file, a pass/fail).

One problem → one **brief**.

A vibe with no outcome is not a problem. If the list is empty → stop (insufficient source). Do not invent a task so a **wave** can run.

## Brief

Each brief is a short file in scratch `briefs/` (copied into the seal later):

- the problem statement
- paths to work artifacts **as they will appear inside the tester copy**
- the completion the tester should produce

The brief states the problem. It omits the teacher’s answer, their methods, and any **rubric** item.

## Done

`briefs/` has one file per checkable problem. Reading a brief does not reveal the solution or the insisted methods.
